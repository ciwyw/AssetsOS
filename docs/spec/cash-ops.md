# 现金操作、直接编辑与删除

对应源码：`AssetsOS/Editors.swift`（CashTransferView、各编辑器、DeleteAssetView）、`AssetsOS/Engine.swift`（MutationService）

## 金额输入的统一规则

| 场景 | 输入框初值 | 保存/确认按钮 |
|---|---|---|
| 新建现金、新建投资、新建定期 | **空白**（placeholder `0.00`） | 未填金额时置灰 |
| 编辑已有资产 | 真实已保存值；真实值为 `0` 时显示 `0` | 按各表单必填项判断 |
| 转入 / 转出 | **始终空白** | 金额为空或 ≤ 0 时置灰 |

现金资产允许保存金额为 `0`（只拒绝负数）。投资类编辑要求累计投入、累计取回、当前市值三项都有值。

## 转入 / 转出

入口：活期和活期+ 详情页的"转入"、"转出"按钮。投资类和定期没有转账入口。

### 表单结构

**第一段 · 金额**

- 标签：转入为 `转入到 {账户名 · 资产名}`，转出为 `从 {账户名 · 资产名}`
- 金额输入框，默认空白
- **转出**时右侧有 `全部` 按钮，点击把金额填满当前余额；余额 ≤ 0 时禁用
- 脚注 `未填写金额前无法确认。`

**第二段 · 来源（转入）/ 去向（转出）**

只有两行：

1. `外部` —— 副文案 `从 App 外转入` / `转出到 App 外`，**默认选中**
2. `现金资产` —— Picker 选择另一笔活期或活期+

切回 `外部` 时会清空已选的现金资产。脚注说明 `切回外部会清空已选现金资产。`

**第三段 · 影响预览**

- 当前资产余额 `当前 → 转账后`（结果为负时红色）
- 选了内部对手时，显示对手余额的变化
- 总资产变化（带符号和颜色）

### 资金语义

| 路径 | 当前资产 | 对手资产 | 总资产 |
|---|---|---|---|
| 外部转入 | +金额 | — | **+金额** |
| 外部转出 | -金额 | — | **-金额** |
| 内部互转 | ±金额 | 反向 ±金额 | **不变** |

## 证券账户活期的互转限制

证券平台账户下的**活期**（不含活期+）受额外约束：转账页**不显示"外部"选项**，对手方固定为绑定银行账户下的活期，只读展示。

阻断在**进入转账表单之前**就发生——详情页点"转入"或"转出"时先弹提示：

| 条件 | 文案 |
|---|---|
| 缺少所属账户 | `当前证券账户缺少所属账户，暂不能转入转出。` |
| 未绑定银行账户 | `当前证券账户未绑定银行账户，暂不能转入转出。请先在编辑账户里绑定银行账户。` |
| 已绑定但该银行无活期 | `已绑定「{银行名}」，但该银行账户下还没有活期，暂不能转入转出。请先创建活期。` |

保存时二次校验；试图走外部路径会报 `证券账户活期只能与绑定银行账户下的活期互转。`

反向也成立：绑定银行账户下的活期，只能与该证券账户的活期互转。

## 从现有资金买入投资

新增基金 / 股票 / 银行理财时先选创建方式：`录入已有资产` 或 `从现有资金买入`。

**从现有资金买入**：

- 来源候选：全部活期和活期+，**可以跨账户**（来源账户不必等于投资所属账户）
- Picker 文案：`{资产名} · {账户名} · 可用 {余额}`
- 表单字段：实际投入、当前市值。改实际投入时，若当前市值为空或等于旧投入值，会自动同步为相同数值
- 校验：实际投入 > 0，来源余额 ≥ 实际投入

资金语义：

```text
来源现金 -= 实际投入
新投资.当前市值 = 填写的当前市值
新投资.累计投入 = 实际投入
新投资.累计取回 = 0
总资产变化 = 当前市值 - 实际投入
```

注意：与定期不同，投资**不记录来源资产 ID**，删除投资时不会退回来源。

## 直接编辑

允许直接编辑的金额：

| 类型 | 可编辑 | 只读 |
|---|---|---|
| 活期 | 当前余额 | — |
| 活期+ | 当前余额、资金状态 | — |
| 基金 / 股票 / 银行理财 | 累计投入、累计取回、当前市值、解锁日（基金和银行理财） | — |
| 定期（未结清） | 年化、起息日、到期日、持有天数、备注 | 本金、创建方式、本金来源 |
| 定期（已结清） | **仅备注** | 其余全部 |

直接编辑就是字段整体覆盖，不产生流水。转账和"从现有资金"创建走独立的原子操作。

## 删除资产

删除入口在资产详情页底部，点击后弹出确认 sheet（含影响预览卡片）。

### 阻断条件

| 类型 | 阻断条件 | 文案 |
|---|---|---|
| 活期 / 活期+ | 余额 ≠ 0 | `当前余额必须为 0 才能永久删除。` |
| 活期 / 活期+ | 仍是未结清定期的本金来源 | `该现金资产仍是未结清定期的本金来源…` |
| 投资类 | 当前市值 ≠ 0 | `当前市值必须为 0 才能永久删除。` |
| 借出 / 借入 | 恒阻断 | `当前版本不支持删除该类型。` |

### 各类型删除语义

| 类型 | 确认按钮 | 总资产 | 累计投资盈亏 | 现金影响 |
|---|---|---|---|---|
| 活期 / 活期+（余额 0） | 永久删除 | 不变 | 不变 | 无 |
| 基金 / 股票 / 银行理财（市值 0） | 永久删除该投资及其历史 | 不变 | **减去该资产盈亏** | 无 |
| 未结清定期（录入已有） | 确认删除 | **-本金** | 不变 | 无 |
| 未结清定期（从现有资金创建） | 退回本金并删除 | 不变 | 不变 | **本金退回原来源现金资产** |
| 已结清定期 | 永久删除该定期历史 | 不变 | **减去该资产盈亏** | **不回滚**已到账的活期 |

确认页至少展示：删除对象名称、当前总资产变化、累计投资盈亏变化、是否影响其他现金资产、是否不可恢复。

未结清定期的删除是原子操作：退回本金 + 删除记录 + 取消未触发的通知。不提供撤销。
