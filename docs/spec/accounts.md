# 账户

对应源码：`AssetsOS/AccountsScreen.swift`、`AssetsOS/Models.swift`（Account）、`AssetsOS/Editors.swift`（AccountEditorView）、`AssetsOS/Engine.swift`

## 账户类别

五个可选类别，界面顺序固定：

```text
银行
支付平台
基金平台
证券平台
其他
```

"证券平台"是最终文案，界面不使用"券商"。

代码里 `AccountCategory` 还有一个 `personalRelations`（个人往来），但它不在 `v1Cases` 中，因此**不出现在类别选择器和账户页分组里**。

类别只用于账户页分组、总览按平台汇总、图标徽标和固定排序。类别**不决定**账户下允许的资产类型、资金状态、盈亏算法或到期逻辑——任何账户都可以创建全部六种资产类型。

## 账户字段

| 字段 | 必填 | 说明 |
|---|---|---|
| 名称 | 必填 | **全局唯一**，跨类别校验，trim 后精确匹配 |
| 类别 | 必填 | 上述五类 |
| 备注 | 选填 | 空白保存为 `nil` |
| 绑定银行账户 | 证券平台必填，其他类别强制为空 | 见下文 |
| 沪A 股东账号 | 选填 | 仅资料保存，不参与计算 |
| 深A 股东账号 | 选填 | 仅资料保存，不参与计算 |

名称重复时报错文案：`账户名称必须全局唯一。`

## 账户规则

- 一家平台通常只创建一个账户
- 账户不能嵌套，不存在父子账户
- 账户不保存余额；账户金额 = 其当前资产金额之和
- 账户可以在没有任何资产时保留，零资产账户仍显示在账户页
- 名称、类别、备注均可修改；改类别不会改变下面资产的类型或金额

**账户金额口径**：账户下资产（排除已结清定期）的 `currentPortfolioAmount` 求和后按 2 位小数舍入。无缓存，每次渲染实时计算。

## 证券账户绑定银行

证券平台账户必须绑定一个银行账户，这个绑定决定了该证券账户下**活期**能和谁互转（见 [cash-ops.md](cash-ops.md#证券账户活期的互转限制)）。

- 候选范围：全部 `category == 银行` 的账户，按名称升序，排除正在编辑的账户自身
- 库里没有任何银行账户时，Picker 不可用并显示红色提示；保存报错 `请先创建至少一个银行账户，再创建或编辑证券账户。`
- 未选绑定银行时保存报错 `请选择绑定银行账户。`
- 类别从证券改为其他时，界面立即清空绑定银行和沪A/深A；保存时也会强制写空

**反向保护**：已被证券账户绑定的银行账户，改类为非银行时被阻断，报错 `该银行账户已被证券账户绑定，需先去对应证券账户改绑或取消绑定。`

## 删除账户

只有同时满足以下条件才允许删除：

1. 账户下资产记录数量为 0
2. 若为银行账户，没有任何证券账户绑定它

**所有资产记录都会阻止删除**，包括零余额活期、活期+、基金、股票、银行理财、进行中定期、待结清定期，以及**已结清定期**。不提供账户级级联删除。

注意：账户金额显示 `¥0.00` 时仍可能无法删除，因为已结清定期不计入金额但仍算记录。

### 阻断页

标题 `无法删除「{账户名}」`。按阻断原因组合描述文案，并列出：

- **仍存在的记录**：逐项列出阻塞资产，各带提示（活期/活期+ → `余额需先归零`；投资类 → `当前市值需先归零`；定期 → `进行中` / `待结清` / `已结清 · 仍属于本账户历史`）
- **仍绑定的证券账户**：逐项列出，提示 `需先去该证券账户里改绑或取消绑定`

阻断原因含已结清定期时，底部提供 `前往定期页查看已结清` 按钮，点击切到定期页。

### 确认页

标题 `永久删除「{账户名}」？`，说明 `账户为空时才允许删除。该操作不可恢复。`，主按钮 `永久删除账户`。

SwiftData 层 `Account.assets` 用 `deleteRule: .deny` 作为第二道保护。

## 账户页

容器为 `List(.insetGrouped)`，大标题"账户"。**这是系统分组样式，不要改成自绘白底卡片容器**（见 `CHANGELOG.md` 2026-08-19 条目）。

### 分组与排序

按类别固定顺序分组，**只渲染有账户的类别**（空类别整段隐藏），Section 标题为类别名。类别内账户按名称升序。

账户内资产按类型固定顺序，同类型内按名称升序：

```text
活期 → 活期+ → 定期 → 基金 → 股票 → 银行理财
```

不提供拖动排序、排序切换、搜索或筛选。

### 账户行

从左到右：类别单字徽标（28×28，展开时反色）、账户名称 +（可选）备注单行、账户金额、展开箭头（折叠 `chevron.right` / 展开 `chevron.down`）。

账户行**不是** NavigationLink，不存在账户详情页。整行是按钮，点击只切换**当前这一个**账户的展开状态。

### 展开与折叠

- **首次进入默认全部折叠**，账户和资产汇总组的展开状态各自独立记录
- 点击账户行：只切换该账户
- **重复点击底部"账户" Tab**：若当前不是全展开则切到全展开，否则切到全收起。实现是 `TabView` selection 走 `AppCoordinator.handleTabSelection`，识别到已选中的 Tab 被再次点击时递增计数，账户页监听该计数

### 账户行右滑

`edge: .trailing`，**禁用 full swipe**。从右向左依次是：

| 动作 | 图标 | 颜色 |
|---|---|---|
| 删除 | `trash` | `AppTheme.gain`（红褐） |
| 编辑 | `square.and.pencil` | `AppTheme.warning`（黄褐） |
| 添加资产 | `plus` | `AppTheme.accent`（青灰） |

"删除"**不能**用 `role: .destructive`。该动作点击后先弹阻断页或确认页而非立即删行，`.destructive` 会触发 SwiftUI 的乐观删行动画并导致列表 diff 崩溃。

### 账户内资产的两层展示

展开账户后，按资产类型顺序渲染：

- **活期、活期+**：直接列出明细行，没有汇总层
- **定期、基金、股票、银行理财**：先显示类型汇总行，再点一次才展开明细（即使该类型只有一项资产也要多点一次）

只展示当前资产，**已结清定期不在账户页出现**。

**汇总行**：左侧类型名 +（可选）副标题，右侧汇总金额 + 汇总盈亏 + 展开箭头。

- 汇总金额 = 组内 `currentPortfolioAmount` 求和后舍入
- 汇总盈亏**只有投资类**（基金/股票/银行理财）显示，定期汇总行不显示盈亏
- 副标题只有定期有：`最近 {相对到期文案}`，取组内最近到期日
- 汇总行**不带** `X项` 计数

**明细行**：NavigationLink 进资产详情页。左侧资产名称 + 副标题，右侧金额 +（投资类才有的）盈亏。

- 明细行**不显示资产类型文案**（类型信息已在汇总行或分组语境里）
- 明细行**不手工绘制 chevron**，只用 NavigationLink 的系统 disclosure，否则会出现双箭头
- 副标题规则：活期/活期+ → 资金状态名；定期 → `{资金状态} · {相对到期文案或"未设置到期日"}`；投资类 → 资金状态名

### 新增入口与返回行为

| 入口 | 打开 | 保存后 |
|---|---|---|
| 导航栏 `+` | 新增账户 sheet | 关闭 sheet |
| 空状态按钮 | 新增账户 sheet | 关闭 sheet |
| 右滑"编辑" | 编辑账户 sheet | 关闭 sheet |
| 右滑"添加资产" | 资产类型选择 sheet | **同时关闭类型选择页和具体编辑页，直接回账户页** |
| 展开账户后底部"新增资产"行 | 资产类型选择 sheet | 同上 |

新增资产保存后回到账户页，**不自动展开或定位到新资产**。

### 空状态

库里没有任何账户时显示 `ContentUnavailableView`：图标 `rectangle.grid.1x2`，标题 `尚未创建账户`，说明 `先创建银行、支付平台、基金平台、证券平台或其他账户，再在账户里录入资产。`，按钮 `新增账户`。

账户存在但没有资产时，正常显示账户行（金额 `¥0.00`），展开后只有"新增资产"行。

### 跨页跳转

总览页点击账户类别分布行会切到账户 Tab 并滚动到对应类别的 Section。
