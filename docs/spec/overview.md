# 总览页

对应源码：`AssetsOS/OverviewScreen.swift`、`AssetsOS/Engine.swift`（PortfolioEngine 汇总函数）

## 页面结构

`ScrollView` + `LazyVStack`，大标题"总览"。从上到下：

1. **汇总卡片** —— 始终显示
2. **备份横幅** —— 备份状态非正常时显示
3. 无账户时：**空状态卡片**；有账户时依次显示：
   - **需处理** —— 有内容才显示
   - **资金状态**
   - **账户类别分布**
   - **累计投资盈亏**

## 汇总卡片

主数字标签为 **`净资产`**，值是全部当前资产的 `currentPortfolioAmount` 之和。当前没有负债类型，所以净资产等于总资产之和。

下方分隔线后一行显示 `累计投资盈亏` 及其金额（带符号和颜色）。

**总资产口径**：

```text
总资产 = Σ 当前资产的 currentPortfolioAmount
当前资产 = 全部资产 - 已结清定期
```

- 未到期定期按**本金**计入
- **已到期未结清的定期仍按本金计入总资产**，只是在资金状态里归入"应收与待到账"
- 已结清定期完全退出总资产
- 定期的预计利息不计入

## 需处理

**只包含定期到期提醒，不含备份相关提示**（备份走独立横幅）。

| 类型 | 条件 | 标题 | 副标题 |
|---|---|---|---|
| 待结清 | 到期日 ≤ 今天 | `待结清 · {n} 笔`（红色） | `{账户名} · {资产名}，已到期` |
| 即将到期 | 距到期 1~3 天 | `即将到期 · {n} 笔` | `{账户名} · {资产名}，{MM-dd} 到期` |

没有到期日的定期不出现；距到期超过 3 天不出现。排序上待结清优先，同类型按到期日升序。

右侧显示本金。点击任意一项都切到定期 Tab，**不定位到具体资产**。

## 资金状态

四个状态**始终全部展示，即使金额为 ¥0.00**。每行：彩色圆点 + 状态名 + 合计金额 + 展开箭头。

点击展开后显示该状态下的资产明细（资产名、所属账户、金额），子项按金额降序，再按账户名和资产名。

金额口径为该状态下资产的 `currentPortfolioAmount` 之和。判定规则见 [assets.md](assets.md#资金状态)。

## 账户类别分布

展示五个类别（不含"个人往来"），按类别固定顺序排列，显示**绝对金额，不显示占比**。

**金额为 0 的类别整行隐藏。**

点击某行切到账户 Tab 并滚动到对应类别的 Section。

## 累计投资盈亏

四个分项 + 分隔线 + 合计行：

| 分项 | 公式 |
|---|---|
| 基金 | Σ（当前市值 + 累计取回 - 累计投入） |
| 股票 | 同上 |
| 银行理财 | 同上 |
| 已结清定期 | Σ（实际到账 - 本金） |

不包含未结清定期、活期、活期+。脚注 `根据当前记录的投资资产计算`。

颜色与符号规则：正数用 `AppTheme.gain`（红褐）并加 `+` 前缀，负数用 `AppTheme.loss`（绿）自带 `-`，零为次要色无符号。

这个指标同时出现在汇总卡片和本区块，两处口径一致。

## 备份横幅

只有三种状态会出横幅，**没有"多久没备份"的时间过期判定**：

| 状态 | 标题 | 说明 |
|---|---|---|
| 未配置 | 尚未配置备份 | 数据只保存在本机。前往账户页右上角的设置，选择 iCloud Drive 目录。 |
| 失败 | 最近一次备份失败 | 具体错误信息（红色） |
| 待处理旧备份 | 目录中发现旧备份待处理 | 你已经选择空白开始，当前暂停自动写入。请前往设置决定恢复旧备份、覆盖旧备份或更换目录。 |

## 空状态

没有任何账户时显示引导卡片：图标 + `尚未创建账户` + 引导文案 + `新增账户` 按钮（切到账户 Tab 并弹出新增账户）+ 说明 `不预置任何银行、平台或示例资产。`

此时主数字仍显示，但用次要色。
