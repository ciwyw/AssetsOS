# 资产类型与资金状态

对应源码：`AssetsOS/Models.swift`（Asset）、`AssetsOS/AssetDetailScreen.swift`、`AssetsOS/Engine.swift`

## 六种资产类型

```text
活期
活期+
定期
基金
股票
银行理财
```

`AssetKind` 里还有 `loanReceivable`（借出）和 `loanPayable`（借入），当前**没有创建入口**，详情页落到"当前版本暂不支持该资产类型"分支。

## 通用字段与规则

所有资产都有：id、所属账户、资产类型、名称、备注（可选）、createdAt、updatedAt。

- **所属账户保存后不可修改**
- **资产类型保存后不可修改**
- 录错账户或类型时，按删除规则删除后重新创建
- **同一账户下当前资产名称不可重复**（排除已结清定期），错误文案 `同一账户下当前资产名称不能重复。`。名称**不要求全局唯一**，不同账户可以同名
- 金额不能小于零
- 所有金额用 `Decimal`，严禁 `Double`
- 不保存金额修改历史，不提供撤销
- 直接编辑金额后立即重算全部汇总

名称留空时自动命名：活期 → `活期`，活期+ → `活期+`，冲突时追加 ` 2`、` 3`。定期名称强制自动生成，见 [fixed-terms.md](fixed-terms.md#自动命名)。

## 各类型专属字段与金额口径

| 类型 | 专属字段 | 当前金额取自 | 详情页金额标签 | 有盈亏 |
|---|---|---|---|---|
| 活期 | — | `currentAmount` | 当前余额 | 否 |
| 活期+ | `cashAvailability`（直接可用 / 可变现） | `currentAmount` | 当前余额 | 否 |
| 基金 | `totalInvested`、`totalWithdrawn`、`lockEndDate`（可选） | `currentAmount` | 当前市值 | 是 |
| 股票 | `totalInvested`、`totalWithdrawn` | `currentAmount` | 当前市值 | 是 |
| 银行理财 | `totalInvested`、`totalWithdrawn`、`lockEndDate`（可选，界面称"解锁日"） | `currentAmount` | 当前市值 | 是 |
| 定期 | 见 [fixed-terms.md](fixed-terms.md) | **`principal`**（未结清）/ `0`（已结清） | 本金 | 仅已结清 |

**活期每个账户最多一个。**

参与总资产汇总的统一口径是 `currentPortfolioAmount`：定期未结清取本金、已结清取 0，其余类型取 `currentAmount`。定期的 `currentAmount` 字段虽然也会被写入，但**不参与任何汇总**。

## 盈亏计算

投资类（基金/股票/银行理财）：

```text
盈亏 = 当前市值 + 累计取回 - 累计投入
```

已结清定期：

```text
盈亏 = 实际到账 - 本金
```

未结清定期、活期、活期+ 的盈亏恒为 0。定期的"预计利息"仅展示，**不计入盈亏，也不计入总资产**。

详情页对投资类还显示收益率 `盈亏 / 累计投入`，累计投入为 0 时显示 0%。

## 资金状态

四种状态，界面顺序固定：

| 状态 | 判定规则 |
|---|---|
| 直接可用 | 活期；活期+ 且未标记为可变现 |
| 可变现 | 活期+ 且标记为可变现；股票；基金/银行理财且无锁定日或锁定日已过 |
| 锁定中 | 基金/银行理财且锁定日晚于今天；未到期的定期 |
| 应收与待到账 | 已到期未结清的定期 |

除活期+ 由用户手动选择外，其余全部由类型和日期派生，用户无法直接编辑。

## 资产详情页

导航标题为资产名，右上角"编辑"打开对应编辑器。

### 活期 / 活期+

- 主卡片：当前余额（大字）+ 资金状态药丸
- 操作：**转入**（主按钮）、**转出**（次按钮）
- 属性卡片：名称、所属账户、资产类型；活期+ 额外显示资金状态；备注
- 底部删除区：`永久删除` + 副文案（可删则说明条件，不可删则显示阻断原因）

### 基金 / 股票 / 银行理财

- 主卡片：当前市值、累计盈亏（带符号与颜色）、收益率、资金状态
- 属性卡片：累计投入、累计取回、当前市值、累计盈亏
- 第二卡片：基金/银行理财显示解锁日 + 备注；股票只有备注
- 操作：**只有编辑和删除，没有转入转出**

### 定期

见 [fixed-terms.md](fixed-terms.md#定期详情页)。
