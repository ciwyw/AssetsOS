# 定期

对应源码：`AssetsOS/FixedTermsScreen.swift`、`AssetsOS/Editors.swift`（FixedTermEditorView、FixedTermSettlementView）、`AssetsOS/Engine.swift`、`AssetsOS/Support.swift`（DateKit）、`AssetsOS/BackupSystem.swift`（TermNotificationManager）

## 字段

| 字段 | 单位 / 格式 | 必填 | 保存后可改 |
|---|---|---|---|
| 本金 | 元，2 位小数 | 是 | **否** |
| 年化 | 界面输入百分数（`6` 表示 6%），入库存小数（`0.06`，scale 6） | 是 | 是 |
| 起息日 | 业务日期，存本地时区当日 0 点 | 是（默认今天） | 是 |
| 到期日 | 业务日期，存本地时区当日 0 点 | 是（默认今天+30 天） | 是 |
| 持有天数 | 天 | 选填 | **不持久化**，仅表单联动用 |
| 名称 | 自动生成 | — | 随字段变化重新生成 |
| 备注 | 文本 | 选填 | 是（已结清时也可改） |
| 创建方式 | 录入已有 / 从现有资金创建 | 是 | 否 |
| 本金来源 | 来源活期 ID | 从现有资金创建时必填 | 否 |

**保存约束**：到期日必须严格晚于起息日。

## 新增定期表单

**表单内没有名称输入框。** 字段顺序：

1. **创建方式**（仅新建时显示）—— Segmented：`录入已有定期` / `从现有资金创建`
2. **基本信息**
   - 账户 —— 从定期页进入时是 Picker（含"请选择"）；从账户内进入时只读
   - 现金资产 —— **仅"从现有资金创建"时出现**，紧跟在账户字段下
   - 本金 —— 新建可编辑，编辑已有时只读
   - 年化
   - 起息日
   - 到期日
   - 持有天数（选填）
3. **收益预览** —— 只有两行：`预计利息`、`到账本息`
4. **备注（可选）** —— 位于表单最下方

收益预览区脚注：`预计利息 = 本金 × 年化 × 持有天数 ÷ 365，仅展示，不计入总资产与累计投资盈亏。`

名称提示：`保存后名称会自动设置为「{生成的名称}」。`；本金或年化未填时显示 `填写本金和年化后会自动生成名称。`

**新增入口不弹账户选择弹窗。** 定期页右上角 `+` 直接打开表单，账户在表单内选。

## 自动命名

格式：

```text
{本金} / {年化}% / {持有天数}天
```

- 本金 ≥ 10000 时按万元显示并加 `W`（如 `1.5W`）；否则直接显示数字，最多 2 位小数，无货币符号无千分位
- 年化用界面输入的百分数，最多 2 位小数
- 持有天数 = 起息日到到期日的日历天数差

例：`1W / 6% / 30天`

**重名去重**：同账户下当前资产（不含已结清定期）出现同名时，追加 ` / 2`、` / 3`，即 `1W / 6% / 30天 / 2`。**纯序号，不带日期。** 不会因为重名导致保存失败。

## 起息日 / 到期日 / 持有天数联动

三者通过一个"锚点"联动，锚点是**最近一次被编辑的那个日期**，初始为起息日：

- 改起息日 → 锚点设为起息日，按两个日期重算持有天数
- 改到期日 → 锚点设为到期日，按两个日期重算持有天数
- 改持有天数 → 锚点是起息日时，`到期日 = 起息日 + 天数`；锚点是到期日时，`起息日 = 到期日 - 天数`

## 两种创建路径

### 录入已有定期

不涉及任何现金资产。新建后本金直接计入总资产。

### 从现有资金创建

- 来源候选：**只有活期，不含活期+**
- 选项文案：`{账户名} {余额}`，例 `招商银行 ¥10,000.00`
- 脚注：`从现有资金创建仅支持活期作为本金来源。`
- 校验：来源必须是活期，且余额 ≥ 本金

资金语义：

```text
来源活期 -= 本金
新定期本金计入总资产
总资产净变化 = 0
记录 sourceCashAssetID 供删除时退回
```

## 计息与金额

```text
预计利息 = 本金 × 年化 × (起息日到到期日的天数) ÷ 365
到账本息 = 本金 + 预计利息
计入总资产的金额 = 本金（未结清）/ 0（已结清）
```

- 分母固定 **365**，不按实际年天数也不按 360
- 计息天数是**起息日到到期日的全期天数**，不是"已持有天数"。详情页展示的持有进度只是 UI
- 预计利息**只展示**，不进总资产也不进累计投资盈亏

## 状态

三种生命周期状态：

| 状态 | 判定 | 资金状态 |
|---|---|---|
| 进行中 | 未结清且今天 < 到期日 | 锁定中 |
| 待结清 | 未结清且**今天 ≥ 到期日** | 应收与待到账 |
| 已结清 | `settledAt` 有值 | 不参与当前资产 |

**到期日当天算"待结清"**，不算进行中。没有到期日的定期兜底为"进行中"。

## 定期页

### 顶部汇总

两列：

- **进行中** —— 本金合计，副文案 `{笔数} 笔 · 预计利息 {金额}`
- **待结清** —— 本金合计，副文案 `{笔数} 笔 · 最近到期 {日期}`（无则 `--`）

底部说明 `预计利息仅展示，不计入总资产与累计投资盈亏。`

汇总里的"预计利息"只累加进行中的定期，不含待结清。"最近到期"取进行中和待结清里最早的到期日。

### 列表分段

1. **待结清 · {n}** —— 有数据才显示。行内直接有"结清"按钮，**点行不进详情页**
2. **进行中 · {n}** —— 点行进详情页
3. **已结清 · {n}** —— **默认折叠**，可展开

排序：待结清和进行中按到期日升序（越早到期越靠前）；已结清按结清时间降序（最近结清在前）。

已结清区块脚注：`已结清不计入总资产，但仍参与累计投资盈亏，并会阻止账户删除。`

## 定期详情页

**未结清**：

- 主卡片：本金、资金状态、预计利息、到账本息、到期 Banner 或持有进度
- 属性卡片：账户、年化、起息日、到期日、创建方式、本金来源（如有）、备注
- 操作：**结清**（主按钮）、**删除**（次按钮，红色调）

**已结清**：主卡片本金显示 `¥0.00`，展示实际到账；操作只有 `永久删除`（删历史记录）。

## 结清

- 输入：**实际到账金额**，默认预填 `本金 + 预计利息`，提示 `可以与"到账本息"不同，按银行实际到账填写。`
- **到账资产不可选**：自动落到同账户下第一个活期；该账户没有活期且到账金额 > 0 时自动创建一个活期
- 预览区显示活期余额变化、`定期当前金额 {本金} → ¥0.00`、实际盈亏、总资产变化

执行结果：

```text
同账户活期 += 实际到账
定期 currentAmount = 0
定期 settledAmount = 实际到账，settledAt = 当前时刻
本金、日期、来源等字段全部保留
取消该定期未触发的通知
```

已结清记录完整保留在库中：不计入总资产，但盈亏（`实际到账 - 本金`）计入累计投资盈亏，并且**会阻止所属账户被删除**。

## 删除

未结清定期详情页的按钮文案是 **`删除`**（不是"本金或来源有误"），确认后直接删除并返回上一页，**不会自动打开重建表单**。

资金语义见 [cash-ops.md](cash-ops.md#各类型删除语义)。要点：从活期创建的定期删除时本金退回原活期（总资产不变）；录入已有的定期删除时总资产减少本金。两种路径都会取消未触发的通知。

## 通知

- **权限请求时机**：不在启动时请求。第一次需要调度通知时，若权限状态为"未决定"才发起请求
- 设置页只展示权限状态，没有手动请求按钮
- 每条未结清且有到期日的定期最多两条通知：
  - 到期日**前 3 天** 09:00 —— subtitle `还有 3 天到期`
  - **到期日当天** 09:00 —— subtitle `今天到期`
- 通知内容：title 为定期名称，subtitle 为 `{账户名} · {上述文案}`，body 为 `请检查是否需要结清。V1 不会自动到账。`
- 只调度触发时间还在未来的通知，已过期的不补发

重排 / 取消时机：保存未结清定期（先取消再重排）、保存已结清定期（取消）、结清（取消）、删除（取消）、恢复备份（全部取消后全部重排）。**App 冷启动不会重排通知。**
