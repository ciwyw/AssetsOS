## 产品定位

AssetsOS 是面向个人的资产总账，管理分散在银行、支付平台、基金平台和证券平台的资金与投资。

它不是消费记账 App。不要求记录每一笔收入支出，也不依赖完整流水计算资产或收益。

打开 App 要能快速回答：

1. 当前共有多少净资产；
2. 资金主要放在哪类平台；
3. 哪些钱可以直接使用、需要主动变现、仍在锁定、或已到期待到账；
4. 基金、股票和银行理财当前累计盈亏多少；
5. 哪些固定收益产品即将到期或已到期尚未结清。

## 使用方式假设

按低频使用设计：用户主要在查看资产、更新金额、发生大额资金转移或处理定期到期时打开。用户可以直接修改当前余额和当前市值，App 不要求补齐历史操作。

**当前资产状态是所有汇总数字的唯一依据。** 不通过流水、余额快照、修改历史、校准记录或操作事件反推金额。

## 固定边界

- 单人使用，只管理本人资产
- 只支持人民币
- 无账号系统、无服务端
- 不联网获取账户余额、不执行真实转账、不读取短信

## 页面结构

三个一级 Tab：**总览**、**账户**、**定期**。

没有资金记录 Tab、待处理 Tab、设置 Tab、分析 Tab、全局新建中心，也没有全局悬浮新增按钮。

入口分布：

- 设置：账户页右上角齿轮
- 新增账户：账户页右上角 `+`，或总览空状态按钮
- 新增普通资产：从所属账户内进入
- 新增定期：从所属账户进入，或定期页右上角 `+`
- 总览"需处理"点击后切到定期页

## 核心术语

**账户**表示资金所在的平台或渠道（招商银行、支付宝、广发基金、华泰证券）。账户只负责分组，**本身不保存金额**。

**资产**是账户内的具体余额、投资或产品。**所有金额都保存在资产上。**

**资产类型**回答"这笔钱是什么"（活期、基金、定期）。

**资金状态**回答"用这笔钱之前还要做什么"（直接可用、可变现、锁定中、应收与待到账）。

资产类型和资金状态是两个独立维度，不能混用。

## 当前不做

以下能力当前不在范围内，不要主动实现：

搜索、筛选、手工排序、资产配置图、净资产历史曲线、余额历史曲线、周期收益（今日/本月/今年）、现金流统计、收入支出统计、消费分类、预算、工资规则、自动账单、资产核对、待更新、校准、余额快照、修改历史、撤销与版本恢复、部分赎回专用流程、份额与价格、持仓成本、交易批次、自动行情、银行/证券账户直连、短信读取、App 内真实转账、投资建议、多币种、家庭共享、多人编辑、信用卡、房贷、消费贷、Face ID、备份加密、多设备实时同步、补录已结清历史定期、清空全部数据、资金操作时间线、投资清仓、通用资产归档、账户停用、借入借出与个人往来。

模型里有几个为上述能力预留但**当前完全未启用**的字段，见 [data-rules.md](data-rules.md#预留字段)。
